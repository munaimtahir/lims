## How to Read This Document

**Categories:**
- `CORE_CODE` - Essential application code (backend/frontend)
- `CORE_DOCS` - Essential documentation for understanding/deploying the system
- `CONFIG` - Configuration files (Docker, build tools, environment templates)
- `DEVOPS` - CI/CD, deployment scripts, automation
- `GENERATED` - Build outputs, compiled files, package manager locks
- `AI_ARTIFACT` - Reports/logs generated by AI agents or automated tools
- `LOG` - Runtime logs, debug outputs
- `EXPORT_DUMP` - Database dumps, config exports, snapshots
- `DUPLICATE` - Redundant copies of existing files
- `UNUSED` - Obsolete files no longer referenced
- `SECRET_RISK` - Files containing or potentially containing secrets
- `UNKNOWN` - Uncertain classification requiring manual review

**Confidence Levels:**
- `High` - 90%+ confident in categorization and recommendation
- `Med` - 60-90% confident, requires validation
- `Low` - <60% confident, requires manual review

**Recommended Actions:**
- `KEEP` - Essential file, do not modify
- `MOVE_TO_ARCHIVE` - Preserve in archive/ directory for history
- `DELETE` - Safe to remove, no functional impact
- `REPLACE_WITH_TEMPLATE` - Replace hardcoded values with generic template
- `REVIEW_MANUALLY` - Uncertain, needs human judgment
